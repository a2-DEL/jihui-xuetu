## 📖 项目背景

高校学生资助工作长期面临**政策复杂、流程冗长、部门协同难、资金安全压力大、学生体验差**等痛点。传统系统要么只做了申请录入，要么只做了简单审批，缺乏从学生申请到银行放款的全链路闭环，更缺乏 AI 辅助和全程审计能力。

**冀慧学途**以"人工把控 + AI 辅助"为核心理念，将资助申请、资格认定、多级审批、资金发放、银行对账、监管报送、信用评价、全链路审计统一到一个工作台，让每一次审批、每一笔资金、每一次数据访问都**有权限、有依据、可回溯**。

> 📌 挑战杯参赛作品，内置 17 类角色、完整业务状态机与脱敏模拟数据，docker run 即可体验全流程。

## ✨ 核心优势

### 🔐 首创：九维授权引擎

不是简单的"登录后就能看"，而是**九个维度同时判定每一次操作**：

```
请求 → ①角色 → ②组织 → ③数据范围 → ④时间窗口 → ⑤地理位置
     → ⑥工作流节点 → ⑦AI风险等级 → ⑧数据敏感度 → ⑨操作类型
     → 判定：ALLOW / DENY / PENDING_APPROVAL / ESCALATE
```

- 学生只看自己，辅导员看班级，院系看本院系，学校看全校
- 身份证号、银行卡号按 P0-P5 分级自动脱敏遮罩
- 非工作时间导出敏感数据需二次审批
- AI 操作和人工操作走同一套权限判定

### 🤖 AI Agent「小海豚」—— 不碰钱的智能助手

| AI 能力 | 场景 |
|---------|------|
| 自然语言查询 | "我班上个月几个助学金申请？" → 直接出结果 |
| 审批建议 | AI 预审材料完整性，给出风险提示，但不能替人批 |
| 政策问答 | 资助政策文件智能检索 |
| 报告生成 | 自动生成院系资助统计、资金使用报告 |
| 风险预警 | 异常申请、重复提交、敏感操作自动告警 |
| 安全护栏 | 资金操作 AI 无写权限，必须人工确认 |

> **设计原则**：AI 是参谋，不是决策者。钱永远由人批。

### 🏦 银校协同 —— 从申请到到账全闭环

学生申请 → 多级审批 → 公示 → 财务生成批次 → 银行视频面签 → 放款 → 自动对账

- 视频放款：银行专员远程视频核验学生身份后打款
- 冲突检测：同一学生多批次发放自动查重
- 对账核销：银行回单自动匹配发放批次
- 全链路追踪：从申请到到账每一步可追溯

### 📊 CIAC 监管级驾驶舱

实时大屏、院系排名监控、遗漏学生追踪、教育局口径数据一键导出。

### 🧾 不可抵赖的全链路审计

每次操作留痕、审计日志完整性校验（防篡改）、外部审计独立查阅、隐私请求（谁看过我的信息）。

## 👥 17 类角色 · 全角色协作

```
决策层：校领导 · 资助中心领导 · 学工部
执行层：资助中心管理员 · 财务 · 院系管理员 · 辅导员
学生端：学生（个人资助画像、申请提交、进度查询）
外部协同：银行专员（视频放款、对账）· 教育局（监管报送）
监督治理：内部审计 · 外部审计 · 纪检 · 数据管理员 · 舆情
技术平台：系统管理员 · AI 运维管理员
```

每个角色登录后看到的是**完全不同的工作台**，数据范围、菜单、AI 助手都不同。

## 🔄 业务全流程

```
学生提交申请 → 材料上传 → 辅导员初审 → 院系复审 → 学校终审
    → 公示（接受申诉）→ 财务生成批次 → 银行视频面签 → 放款到账 → 对账核销 → 审计归档
```

覆盖：国家奖学金、励志奖学金、国家助学金、临时困难补助、绿色通道、学费减免、困难生认定、申诉复议。
